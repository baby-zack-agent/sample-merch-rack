# Sample Merch — demo storefront

A sample merch shop built as a demo: cream background, a virtual clothing rack
with swaying tees on wooden hangers, a product carousel, a shoppable grid,
and a working (demo-only) cart drawer.

Static site — no build step, no backend. Cart lives in memory.

## Run locally

```bash
cd sample-merch-site
python3 -m http.server 8080
# open http://localhost:8080
```

## Deploy

Hosted on Vercel. Any static host works — just serve the folder.
